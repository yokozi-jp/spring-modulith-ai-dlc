# 非機能要件

- [非機能要件定義の進め方](definition-process.md)：非機能要件を洗い出す、優先度を付けて定量化する、関係者と合意して確定するとき
- [非機能要件の適用範囲と合意相手](scope-and-stakeholders.md)：非機能要件を保証する範囲と外部依存の扱い、環境ごとの適用範囲、合意する相手を決めるとき
- [非機能要件のフレームワークと用語](frameworks.md)：検討の出発点にするフレームワークを選ぶとき、観点の抜けを点検するとき
- [非機能要件と検証するテストの対応](verification-mapping.md)：目標値をどのテストで検証するかを確かめるとき、テスト計画から抜けている要件を探すとき
- [可用性要件の定め方](availability-requirements.md)：運用スケジュール、RTO と RPO、稼働率とその計算条件を決めるとき、高可用性要件へ進むかを判断するとき
- [高可用性要件と稼働率の扱い](availability-high.md)：可用性が重要ドライバのときに、要求値を引き出す、設計値を見積もる、停止の数え方や見直しの機会を決めるとき
- [耐障害性の要件と設計の分担](fault-tolerance.md)：障害耐性の範囲、単一障害点、フェイルオーバー、依存先が止まったときに止めるか縮退するかを決めるとき
- [災害対策と事業継続の要件](disaster-recovery.md)：広域障害からの復旧レベル、待機サイトの場所、BCP との整合を決めるとき
- [可用性の定義項目チェックリスト](availability-checklist.md)：可用性要件を網羅的に点検するとき、要件定義の叩き台を作るとき
