# 非機能要件と検証するテストの対応

非機能要件の目標値は、検証するテストの種別と対にして定める。
要件からテストへたどって数値が検証できるかを確かめ、テスト計画から要件へたどって抜けている要件を探す。
対応するテストが思い当たらない要件は、検証方法を一緒に決める。

目標値の置き方は[非機能要件定義の進め方](definition-process.md)に従う。
性能と拡張性のテストの計画と実施は[性能テストの計画](../performance-test/test-planning.md)に従う。

| 非機能要件の項目         | テストの種別               | 主な検証項目                                     |
| ------------------------ | -------------------------- | ------------------------------------------------ |
| 可用性                   | 障害テスト                 | 冗長性、フェイルオーバー、バックアップとリストア |
| 可用性                   | DR の切り替えと切り戻し    | RTO、RPO                                         |
| 性能と拡張性             | ボリュームテスト           | レイテンシ、限界データ量                         |
| 性能と拡張性             | ラッシュテスト             | スループット                                     |
| 性能と拡張性             | ストレステスト             | 限界負荷での性能                                 |
| 性能と拡張性             | スパイクテスト             | 突発的な負荷での性能                             |
| 性能と拡張性             | ロングランテスト           | 耐久性                                           |
| 運用と保守性             | 運用テスト                 | 監視アラート、計画停止、縮退運転                 |
| 移行性                   | 移行テスト                 | 環境の移行、データの移行                         |
| セキュリティ             | 脆弱性診断                 | アプリケーションの脆弱性                         |
| セキュリティ             | ペネトレーションテスト     | 侵入の可能性                                     |
| セキュリティ             | アクセス権限と認証のテスト | 権限の制御                                       |
| 使用性とアクセシビリティ | アクセシビリティテスト     | 適合レベルごとの達成基準                         |
