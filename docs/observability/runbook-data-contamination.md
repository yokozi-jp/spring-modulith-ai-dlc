# 可観測性データ混入対応

アプリケーションから渡さないと決めた値を可観測性データから検知した場合は、生成停止から記録までを順に実施する。
例外メッセージに混ざった個人データは、保存先の閲覧の制限と表示時のマスクで扱うため、この手順の対象外とする。
ただし、例外メッセージに秘密情報が入っていた場合は対象にする。
渡さない値と保存先の要件は[可観測性データの規約](conventions.md)に従う。
この手順の根拠は [ADR-015](../adr/ADR-015-structure-and-protect-observability-data.md) に記録している。

## 対応手順

1. 該当ログの生成を止める。
2. 対象期間とデータ種別を特定し、保存先で削除する対象を確定する。
3. 保存先から対象データを削除し、削除結果を確認する。
4. 混入した値が秘密情報なら、その秘密情報をローテーションする。
5. 対象データへのアクセス履歴を確認する。
6. 対象期間、データ種別、削除結果、再発防止をインシデント記録へ残す。

## 完了条件

次の条件をすべて満たした時点で対応を完了する。

- 該当ログの生成が停止している。
- 対象期間とデータ種別を特定し、対象データの削除結果を確認している。
- 秘密情報が混入した場合は、その秘密情報をローテーションしている。
- 対象データへのアクセス履歴を確認している。
- 対象期間、データ種別、削除結果、再発防止をインシデント記録へ残している。
