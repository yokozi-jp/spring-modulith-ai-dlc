# 可観測性とログ

- [可観測性データの規約](conventions.md)：ログと例外の記録、相関、発生源で渡さない値、Collector の allowlist、保持、アクセス、本番の受け入れ条件を確認するとき、Collector の設定を変えるとき、本番のロググループを作るとき
- [可観測性データ混入対応](runbook-data-contamination.md)：アプリケーションから渡さないと決めた値（秘密情報、意図して出した個人データ）を可観測性データから検知し、生成停止、削除、確認、記録を行うとき
- [ログレベルの使い分けと切り替え](log-levels.md)：ログを出力するコードでレベルを選ぶとき、環境のログレベルを変えるとき
- [ログメッセージと属性の書き方](log-messages.md)：ログ出力を書くとき、ログに属性を追加するとき、エラーを利用者へ表示するとき
- [処理ごとに記録するログ](log-output-points.md)：起動処理、HTTP アクセスログ、大量件数を扱う処理を実装するとき、ブラウザでエラーを収集したくなったとき
- [運用者が対応するログイベントの管理](log-operational-events.md)：WARN 以上のログを追加または変更するとき、ログの通知を設計するとき
- [ログの出力コストと量の抑制](log-performance-and-cost.md)：Logback の appender を変更するとき、性能問題やログ費用を調べるとき
