# 紙帳票の印刷方式と用紙

紙帳票は、サーバーが PDF を生成し、利用者がブラウザから印刷するオンデマンド印刷を原則とする。
システムがプリンタへ直接印刷する自動印刷は人が操作する余地のない業務に限り、大量一括出力ではプリンタフォントを使う。
プリンタはシステムより寿命が短い前提で、ドライバと保守の継続性を確認して選ぶ。

## 印刷方式

| 観点               | オンデマンド印刷                                                    | 自動印刷                                                   |
| ------------------ | ------------------------------------------------------------------- | ---------------------------------------------------------- |
| 内容               | ブラウザで PDF を表示し、利用者の操作で印刷する                     | システムがバックグラウンドでプリンタへ印刷を要求する       |
| プリンタとの結合   | 疎結合で、システムはプリンタを知らない                              | 特定のメーカーと機種に依存する                             |
| 処理性能           | 数千枚の PDF をブラウザで開くと端末が固まるため、大量印刷に向かない | プリンタの物理的な上限まで速度が出る                       |
| 専用用紙と物理制御 | 向かない                                                            | 給紙トレイやカッターなどを制御できる                       |
| プレビュー         | PDF でそのまま確認できる                                            | プレビュー用の PDF を別に作る                              |
| 保守               | ブラウザの PDF ビューアの仕様変更に影響されることがある             | プリンタの生産終了でアプリケーションと帳票の作り直しが要る |

- オンデマンド印刷を第一に選ぶ。窓口業務、対面販売、ラベルの個別発行のように、印刷の数と頻度が少ない業務に適する。
- オンデマンド印刷では、サーバーは PDF の生成だけを行い、プレビュー、印刷、用紙切れと紙詰まりの対応は利用者の端末に任せる。
- 自動印刷は、郵送用の大量一括出力、無人倉庫での自動発行、即時性が要る製造ラインのように、人が操作する余地のない業務に限る。
- 自動印刷を採用する場合は、プリンタの機種と帳票ミドルウェアへの依存を一か所に閉じ込め、採用の判断を ADR に残す。
- 自動印刷で用紙切れや紙詰まりが起きたときの検知方法と業務の運用は、自動印刷を採用するときに決める。

PDF の生成は [PDF 帳票の設計](pdf.md)に従う。

## 印刷フォント

| 方式             | 内容                                               | データ量          | 印刷速度                     | 対応するプリンタ             |
| ---------------- | -------------------------------------------------- | ----------------- | ---------------------------- | ---------------------------- |
| 画像モード       | 端末かサーバーでページを画像にしてプリンタへ送る   | ページあたり数 MB | 転送と展開に時間がかかる     | どのプリンタでもよい         |
| プリンタフォント | 文字コードだけを送り、プリンタ内蔵のフォントで描く | ページあたり数 KB | プリンタの性能の上限まで出る | 必要なフォントを搭載した機種 |

- 自動印刷による大量一括出力では、プリンタフォントを第一に検討する。数千枚を画像で送ると、ネットワーク帯域を圧迫し、印刷の完了まで数時間かかるおそれがあるためである。
- プリンタフォントを使う場合は、帳票で使うフォントをプリンタへ導入する。

## 用紙

用紙は、帳票の用途、印刷方式、プリンタの要件から選ぶ。

| 形状     | 内容                                       | 主な用途                           | 対応するプリンタ                 |
| -------- | ------------------------------------------ | ---------------------------------- | -------------------------------- |
| カット紙 | A4 や B5 などの定型サイズに断裁した用紙    | 請求書、見積書、社内文書           | レーザー、インクジェット         |
| 連続紙   | ミシン目でつながり、左右に送り穴がある用紙 | 大量一括出力、複写伝票             | ドットインパクト、ラインプリンタ |
| ロール紙 | 巻いた紙に印刷し、切り離して使う用紙       | レシート、物流ラベル、入場チケット | サーマル、ラベルプリンタ         |

加工と素材によって、費用と運用が変わる。

- **無地**：何も印刷されていない用紙。システムが罫線やロゴを含めてすべて印字する。
- **プレプリント**：ロゴ、罫線、約款などを印刷所で印刷済みの用紙。システムは文字だけを印字し、大量印刷のトナーの費用を抑え、カラーのロゴを再現できる。
- **ミシン目とパンチ穴**：切り離しやファイリングのための加工。
- **ノーカーボン紙**：圧力で発色する複写用の用紙。ドットインパクトプリンタで打撃して印字する。
- **感熱紙**：熱で発色する用紙。インクとトナーが要らず運用費用は低いが、長期保存に向かないため保存義務のある帳票に使わない。

## プリンタの選定と保守

- ドットインパクトプリンタや連続帳票用のページプリンタは市場が縮小しているため、機種を選ぶときに供給と保守の継続予定を確認する。
- 古いプリンタを使い続ける場合は、クライアント OS を更新した後もドライバが提供されるかを確認する。
- 専用プリンタの保守契約は本体価格と同等以上になることがあるため、保守費用を長期の予算に含める。
- システムよりプリンタの寿命が短い前提で、プリンタのリプレースの予算を確保する。
