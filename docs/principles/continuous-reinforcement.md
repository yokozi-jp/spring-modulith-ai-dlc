# 学びを仕組みへ還元し続ける

作業で得た学びは、その作業の中でコード、検査、docs のいずれかへ還元し、同じ誤りが次に起きないようにする。
還元先は5つの層から選び、誤りを書けなくする上の層ほど優先する。
還元は元の作業と同じ Pull Request に含める。
この方針を採った理由は [ADR-071](../adr/ADR-071-reinforce-learnings-into-five-layers.md) にある。

## 用語

- **還元**：作業で得た学びを、コード、検査、docs の変更として残すこと。会話、コミットメッセージ、Pull Request のコメントだけに残すことは含めない。

## 還元する契機

次のいずれかに当てはまったら、その作業の中で還元する。

- 不具合を直したとき。原因になった書き方を次に書けなくするか、書いたら検出できるようにする。
- レビューで指摘を受けたとき、または指摘したとき。観点の振り分けは[レビューで人が確認する範囲](../code-review/review-scope.md)に従う。
- コーディングエージェントが誤った変更をしたとき、規約を読み違えたとき、同じ質問を繰り返したとき。
- ローカルと CI の検査をすり抜けた問題が、E2E テスト、レビュー、本番などの後の工程で見つかったとき。
- 新しい規約や設計上の判断を決めたとき。検査で表せる部分は、規約の文章と同じ変更で検査にする（[アーキテクチャの制約の自動検証](architecture-fitness-functions.md)）。
- docs に書かれていない暗黙の方針に従って作業していると気付いたとき。

## 還元しないもの

- 実際には起きていない、想定だけの誤り。検査や規約は、誤りが実在するか起きかけた時点で追加する。
- 一度きりの事情による誤りで、仕組みに残しても再発を防げないもの。

## 層の優先順位

上から順に検討し、最初に成り立つ層へ還元する。

1. **アーキテクチャ**：モジュール境界、公開範囲、専用の部品への集約によって、誤った書き方そのものをできなくする。構成は[バックエンドアーキテクチャ](../backend/architecture.md)と[フロントエンドアーキテクチャ](../frontend/architecture.md)に従う。
2. **型と静的検査**：型、コンパイラ、Spring Modulith の検証、ArchUnit、Error Prone、PMD、Lint の規則で、誤りをローカルと CI で検出する。既存の検査は[バックエンドのアーキテクチャテスト](../backend/architecture-tests.md)と[Lintとテストのリファレンス](../tooling/lint-and-test.md)にある。
3. **振る舞いのテスト**：誤った振る舞いを再現するテストを書き、CI で検出する。不具合の修正では、修正前に失敗するテストを残す。テスト種別は[バックエンドのテスト種別](../backend/testing-strategy.md)、[テスト観点の割り当て](../frontend/test-strategy.md)、[E2E テストの方針と書き方](../e2e/testing-strategy.md)で選ぶ。
4. **エージェント向けの docs**：検査で表せない方針を docs の規約、ADR、用語集に書き、steering と `AGENTS.md` から案内する。置き場所は[steering、docs、iwe の役割分担](../knowledge/knowledge-architecture.md)と[コーディングエージェントを前提にした標準化](ai-assisted-development.md)に従う。
5. **人のレビュー**：要求を満たしているか、文脈に依存して規約にできない点だけを人が確かめる（[レビューで人が確認する範囲](../code-review/review-scope.md)）。

## 層の選び方

- 上の層で防げる学びを、下の層だけに還元しない。検査で表せる方針を docs の文章だけで済ませない。
- 一つの学びを複数の層へ還元してよい。検査を追加した場合も、その規約と検査方法は docs に書く。
- 上の層への還元が元の作業より大きな変更になる場合は、下の層へ先に還元し、上の層への移行を Issue に残す（[暫定対応と運用回避の扱い](temporary-workarounds.md)）。
- 戻しにくい還元や複数モジュールに影響する還元は、[ADR の運用ルール](../adr/conventions.md)の基準に当たれば ADR を起こす。
