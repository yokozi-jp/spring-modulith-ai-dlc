# Pull Request の入口

詳細は `docs/pull-request/index.md` から必要な文書だけ読む。

## 行動指針

- Pull Request の本文は `.github/PULL_REQUEST_TEMPLATE.md` を読んで各節を埋める。
- ブランチ保護と必須チェックは `docs/repository/branch-protection.md` に従う。
- 変更の内容をレビューして問題を探すときは、steering `code-review` を使う。
